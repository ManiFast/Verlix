Пакет установки Velrix 1.0.1 на основе пользовательского проекта приложения версии 1.0.0.

Setup.exe включает официальный офлайн Runtime .NET Framework 4.8 и MSI. При сборке проверены подпись Microsoft и версия Runtime; совместимый установленный Framework пропускается. MSI отдельно предназначен для ПК с Framework 4.8 или совместимым более новым 4.x.

Код приложения сохранён из пользовательского RAR без изменений. Сборка Windows, открытие окна и установка/удаление проверяются CI. На CI уже есть .NET 4.8: проверяется пропуск установленного Runtime; ветка установки отсутствующего Runtime отдельно на чистой клиентской Windows ещё не испытана.
