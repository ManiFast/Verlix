Velrix 1.0.0 — Windows, C# / WPF, .NET Framework 4.8.

Пять проверок: доступность четырёх HTTPS-адресов, состояние антивируса, реакция на выбранный EICAR, профили брандмауэра Windows и контроль исходящего TCP-соединения временным правилом.

MSI для 64-разрядной Windows устанавливает приложение и ярлык в меню «Пуск». Требуется .NET Framework 4.8 либо совместимый более новый 4.x. Приложение запрашивает права администратора для контрольного правила. Тестовый файл EICAR выбирается отдельно и не включён в установщик.

Сборка, инициализация окна, установка и удаление проверяются в GitHub Actions до публикации. Реакцию Defender и фильтрацию следует проверять на целевом ПК; автоматическая сборка эти действия не выполняет.
