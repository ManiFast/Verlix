# Velrix

Утилита проверки антивирусной защиты и брандмауэра Windows. C#, WPF, .NET Framework 4.8. Лицензия MIT.

[Скачать выпуск](https://github.com/ManiFast/Verlix/releases/latest) · [Сборки](https://github.com/ManiFast/Verlix/actions)

## Проверки

- Интернет: HTTPS HEAD к четырём выбранным серверам, время запросов. Это не ICMP ping и не оценка всех сайтов страны.
- Антивирус: название и сообщаемое состояние через Windows Security Center.
- EICAR: выбранный пользователем TXT проверяется по содержимому и копируется в собственную тестовую папку. Антивирус может реагировать на чтение или запись; файл не запускается. Подтверждение — коды Windows 225/226 либо соответствующее новое событие Defender 1116. Собственная копия убирается в finally.
- Брандмауэр Windows: активные профили и значения FirewallEnabled для доменной, частной и общедоступной сетей.
- Контроль фильтрации: новое TCP-соединение до запрета, при собственном временном правиле и после удаления правила. Правило ограничено текущим EXE, одним внешним IPv4, TCP-портом 443 и активными профилями. Успех требует исходного соединения, отказа 10013, подтверждённого удаления и восстановления соединения. Тайм-аут сам по себе не доказывает блокировку.

Подробности сохраняются в TXT; вкладка «События» содержит короткие записи, «Технический вывод» — реальные вызовы API и ответы. Cmd и PowerShell для проверок программой не запускаются. Утилита не является антивирусным движком или полноценным сканером уязвимостей.

## Установка

1. Скачать `Velrix-1.0.0-x64.msi` из Releases и выполнить установку.
2. Открыть Velrix через меню «Пуск». Приложение запросит повышенные права: они нужны для временного правила.
3. Выбрать подготовленный TXT EICAR, нажать «Запустить проверки», затем сохранить TXT кнопкой дискеты или Ctrl+S.

Требуется 64-разрядная Windows 10/11 и .NET Framework 4.8 либо совместимый более новый 4.x. MSI проверяет наличие Framework; сам Runtime не включён. EICAR не включён в приложение или установщик. Portable ZIP содержит ту же программу без установки.

При обычной отмене/закрытии окна завершается очистка. Принудительное завершение процесса может оставить узкое правило: до его добавления записывается памятка с точной командой удаления в `%LOCALAPPDATA%\Velrix\FirewallRecovery`. При нормальном завершении памятка удаляется. Исходный TXT и чужие правила программа не изменяет.

Состояние профиля и один контрольный тест не охватывают все направления, порты, политики и сторонние экраны. Прямой TCP-тест не использует HTTP-прокси и проверяет IPv4. Неподтверждённый результат выводится отдельно.

## Исходники и сборка

Открыть `Velrix.sln` в Visual Studio 2022 с компонентами WPF и .NET Framework 4.8. В решении сохранено пространство имён `Mobks.SecurityCheck`, выходной файл называется `Velrix.exe`.

- `src/Velrix/MainWindow.xaml` — окно и строки результатов.
- `MainWindow.xaml.cs` — управление запуском, сеть, чтение состояний Windows и TXT.
- `EicarTest.cs` — проверка образца, рабочая копия, реакция и очистка.
- `FirewallTest.cs` — контрольные соединения и временное правило.
- `TechnicalLog.cs` — журнал одного запуска.
- `installer/Product.wxs` — MSI, проверка Framework, ярлык и удаление.

Для сборки MSI нужны MSBuild и WiX Toolset 3.14. Из Developer PowerShell:

```powershell
.\scripts\Build.ps1
```

GitHub Actions на Windows собирает приложение и MSI, инициализирует окно без запуска проверок защиты, проверяет установку/удаление на временной машине. Артефакты содержат MSI, portable ZIP, SHA256 и диагностические логи. Первый успешный запуск публикует v1.0.0; для следующего выпуска следует поднять версию в проекте и сценариях выпуска.
